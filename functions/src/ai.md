# Reading AI

The server owns question validation, prompts, default models, routing, and quotas. Documents are untrusted source data. Answers cite numbered paragraphs; markers outside the supplied document are removed from streamed answers, and only in-range references are returned as citations. Thread history contains completed turns. Streaming responses report actual model, completion, interruption, and provider errors. The frontend saves completed or interrupted answers and permits retry or deletion.

Nvidia Nemotron 3.5 Super is selected initially. Named free models fall back to the Free Model Router through OpenRouter's native ordered model routing. Maximum reasoning effort is requested and mapped to supported provider levels. The owner key is stored in Secret Manager and available only to the request function. Ask and import requests are limited per identity per minute, per IP per day, and globally per day. Web search runs only for fact-checks through OpenRouter's web plugin; every other action stays on the source text, and a client web flag alone never enables search.
